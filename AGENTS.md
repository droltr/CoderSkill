# CoderSkill Agent Instructions

## No assumptions / Keine Annahmen / Sin suposiciones / Varsayım yapma

- **EN:** Do not make assumptions. Inspect and verify the relevant primary source, file, or output before making a claim or taking action. Never present unverified information as fact. State uncertainty explicitly and ask the user when needed.
- **DE:** Triff keine Annahmen. Prüfe und verifiziere die maßgebliche Primärquelle, Datei oder Ausgabe, bevor du eine Aussage machst oder handelst. Stelle Ungeprüftes niemals als Tatsache dar. Benenne Unsicherheit ausdrücklich und frage bei Bedarf nach.
- **ES:** No hagas suposiciones. Inspecciona y verifica la fuente primaria, el archivo o la salida pertinente antes de afirmar algo o actuar. Nunca presentes información no verificada como un hecho. Expresa la incertidumbre explícitamente y pregunta al usuario cuando sea necesario.
- **TR:** Varsayımda bulunma. İddia veya işlemden önce ilgili birincil kaynağı, dosyayı ya da çıktıyı incele ve doğrula. Doğrulanmamış bilgiyi asla gerçek gibi sunma. Belirsizliği açıkça belirt ve gerekiyorsa kullanıcıya sor.

For repository work, read `.agents/skills/professional-coding/SKILL.md` first. Use the smallest focused skill for narrow requests. Read `.coderskill/project.yml` when present. Write repository artifacts in English and communicate in the project-selected language, defaulting to English and suggesting the system language. Preserve `main`, use issue-linked topic branches, run validation, and never expose secrets or perform hardware writes.
