# CoderSkill Agent Instructions

## No assumptions

Do not make assumptions. Inspect and verify the relevant primary source, file, or output before making a claim or taking action. Never present unverified information as fact. State uncertainty explicitly; stop only the action that depends on it and ask the user when the answer changes what gets built.

For repository work, read `.agents/skills/professional-coding/SKILL.md` first. Use the smallest focused skill for narrow requests. Read `.coderskill/project.yml` when present. Write repository artifacts in English and communicate in the language set by the project profile or by the user's own instructions. Carry requested work through without asking whether to continue; stop only for the reasons listed in `professional-coding`. Preserve `main`, use issue-linked topic branches, run validation, and never expose secrets or perform hardware writes without authorization.
